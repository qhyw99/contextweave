# 外部数据传输与授权

绘图内容只发送到 ContextWeave 官方服务 `https://pptx.chenxitech.site`；支付账单与支付授权只由支付宝官方 `alipay-bot` / `alipay-payment-skill` 处理。本任务首次联网前，简要说明将发送的数据类别和用途并取得一次明确同意；用户未同意时不执行 `probe`。

同一任务内，已披露类别可以继续用于生成、修改、导出和轮询，不重复询问。只有后来新增完整 CW、绝对本地路径、邮箱或反馈内容等敏感类别时，才补充说明新增类别并再确认一次。用户提供数据本身不等于同意外发。

## 数据说明

| 操作与端点 | 数据类别 | 用途 |
|---|---|---|
| 付费探测、绘图或修改 `POST /a2m/run` | `user_request`；修改时还包括完整 `initial_cw_code`；链接注入时还包括绝对 `base_path` | 创建与本次请求绑定的 A2M 账单，并在支付后生成或修改图 |
| 支付宝官方支付组件 | 签名后的 `Payment-Needed`、付费资源 URL、最小化意图摘要；支付后由官方组件处理 `Payment-Proof` 与交易状态 | 展示收银、取得用户授权、查询支付并确认履约 |
| 导入 `POST /session/import` | 完整 `cw_code` 和可能包含本地绝对路径的 `source_name` | 创建云端会话 |
| 导出或继续处理 `/session/export`、`/export-session`、`/session/recompile` | `session_id`，导出时还包括 `format` | 找回、导出或继续处理当前图 |
| 反馈 `POST /api/feedback` | `session_id`、`user_complaint`、`agent_analysis`，可能包含用户自愿提供的邮箱 | 排查问题与后续联系 |

服务端还会看到 HTTPS 连接所需的常规网络元数据。不得显示完整账单、`Payment-Proof`、交易号、CW 全文或绝对路径，也不要承诺未明确说明的数据保留周期。付费 Skill 不读取或发送免费版 API Key。

联网授权与付款确认是两个不同的门：联网授权允许 `probe` 发送绘图请求并取得账单；只有展示签名账单中的商品和真实金额并获得用户本次明确确认后，才可拉起支付宝收银。用户同意联网、安装 Skill 或提出绘图请求都不构成付款确认。

## 简短询问模板

根据当前任务删去不涉及的项目，一句话说明即可：

```text
ContextWeave 需要把本次绘图要求〔如涉及：现有 CW / 工作区绝对路径〕发送到官方服务 pptx.chenxitech.site，用于创建 A2M 账单并在支付后生成或修改图；账单与支付授权由支付宝官方组件处理。本次联网授权不代表同意付款，实际金额出来后会另行确认。是否同意？
```

如果用户之后新增了未披露的敏感类别，只说明新增项并询问一次，例如：“新增文件链接需要发送工作区绝对路径，用于生成可打开的本地链接，是否同意？”
